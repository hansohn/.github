# Support

Thanks for using this project! Here's how to get help.

## Before You Ask

- Read the project's README and any docs in the repository.
- Search existing issues, open and closed. Your question may already have an answer.

## Asking a Question

Open a new issue and choose **💬 Support Request**. Include:

- What you are trying to do
- What you have tried so far
- The version you are using, plus your OS and environment if relevant
- Error messages, logs or screenshots

## Reporting a Bug or Requesting a Feature

Use the **🐛 Bug Report** or **✨ Feature Request** issue template.

## Security Issues

Do not open a public issue for a security vulnerability. Follow the
[security policy](https://github.com/hansohn/.github/blob/HEAD/SECURITY.md) instead.

## Response Times

This project is maintained in spare time. Support is best effort, and a reply
may take a few days.

## Code of Conduct

Everyone who asks for or gives support must follow the
[Code of Conduct](https://github.com/hansohn/.github/blob/HEAD/CODE_OF_CONDUCT.md).
